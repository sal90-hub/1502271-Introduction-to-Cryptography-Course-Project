# Custom-Engineered AES-128 Cipher ⚙️
The primary objective of this project is the development of a custom-engineered AES-128
cipher: bit-level mathematical implementation, by utilizing the Python programming
language to build the cipher. This project aims to translate the theoretical mechanics of
finite field arithmetic and bit-level transpositions into a functional software architecture. 

In addition to encrypting data, the goal is to show how separate mathematical modules come
together to create a strong Substitution-Permutation Network (SPN). 💻
